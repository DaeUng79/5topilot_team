# 원본 디자인 자료

`simsaimdang/`은 사용자가 제공한 `simsaimdang.zip`을 그대로 풀어 보관한 정적 빌드다.
빌드된 JS/CSS/HTML만 있고 편집 가능한 TSX 원본은 없다. `npm run demo`로 확인한다.
새 기능은 `apps/web`와 `apps/api`에서 개발한다. 원본의 로그인·AI·서명·저장 표시는 데모다.

추가 디자인 참고:

- https://claude.ai/artifact/28ZHSj9yrkE9xMHPN65JwD?v=2
- https://claude.ai/artifact/51Yi3RdVxWcNEtZFy3mRBs?v=2

두 Artifact의 실제 내용은 이번 세션에서 확인하지 못했다. ZIP과 동일하다고 가정하지 않는다.
