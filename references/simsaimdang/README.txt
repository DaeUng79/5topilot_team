심사임당 - 제안평가 지원 시스템 (프론트엔드 데모)

[실행 방법]
이 폴더는 정적 HTML/CSS/JS 파일입니다. 파일을 더블클릭하면 정상 동작하지 않을 수 있으니,
간단한 로컬 서버로 열어주세요.

  예시) 이 폴더에서 아래 명령 중 하나 실행 후 브라우저에서 http://localhost:8000 접속
  - Python: python3 -m http.server 8000
  - Node:   npx serve .

[주의]
- 데모용 화면입니다. 입력한 내용은 저장되지 않으며 새로고침하면 초기화됩니다.
- 첫 화면은 로그인 페이지이며, 역할(총괄 관리자 / 사업부서 담당자 / 평가위원)을 선택해 들어갈 수 있습니다.
