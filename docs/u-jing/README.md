## 개발 내용

- 코드 등록 경로: `apps/api/app/modules/evaluations/`, `apps/api/app/modules/results/`, 업무 migration·테스트
- 산출물: 확정 기준 기반 채점·의견·제출/잠금, 집계·순위·서명·보고서, 업무 데이터 정비
- 현재 확인 상태: 개인 기여 코드와 완료 범위는 아직 확인하지 않았습니다. 기반 PR의 시작용 평가 기능과 향후 서명/보고서 구현을 구분합니다.
- 첫 작업 순서: 기준/배정 계약 → 점수 저장·제출 잠금 → 승인된 계산정책 집계 → 서명/보고서 단계별 검증
- 연결 담당: Lex6won(원준석 PM): 선정/권한/기획, DaeUng79: 기준·근거·문서 DB 연결, cookiesh1: 평가·결과 화면

화면 변경은 cookiesh1과 공동 리뷰합니다. 기획·우선순위·인수 조율은 Lex6won, 저장소 통합은 DaeUng79가 맡습니다. 다른 영역 변경도 이슈에 범위를 알리고 관련 담당자의 검토를 받습니다.

## 실행과 테스트

현재 루트에는 문서 처리 앱이 있습니다. 웹/API는 기반 PR 통합 후 실제 package 설정과 실행 문서를 따릅니다. 존재하지 않는 실행 명령을 완료된 기능처럼 기록하지 않습니다.

[개발 계획](../../team/DEVELOPMENT_PLAN.md)의 선행 조건과 [인수검증표](../../testing/ACCEPTANCE.md)를 사용합니다. 본인의 기능 테스트는 이 문서 작성으로 실행된 것이 아닙니다. 실제 검증 시 아래 기록을 채웁니다.
