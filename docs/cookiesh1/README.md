- 코드 등록 경로: `apps/web/`

- 현재 확인 상태: 독립적인 화면 코드 기여 범위는 아직 확인하지 않았습니다. 데모 화면과 기반 PR의 UI를 출발점으로 코드·PR을 연결합니다.
- 첫 작업 순서: API 계약과 mock으로 화면 개발 → 실제 API 연결 → 새로고침·실패·모바일 화면 검증

화면 변경은 cookiesh1과 공동 리뷰합니다. 기획·우선순위·인수 조율은 Lex6won, 저장소 통합은 DaeUng79가 맡습니다. 다른 영역 변경도 이슈에 범위를 알리고 관련 담당자의 검토를 받습니다.

## 실행과 테스트

현재 루트에는 문서 처리 앱이 있습니다. 웹/API는 기반 PR 통합 후 실제 package 설정과 실행 문서를 따릅니다. 존재하지 않는 실행 명령을 완료된 기능처럼 기록하지 않습니다.

[개발 계획](../../team/DEVELOPMENT_PLAN.md)의 선행 조건과 [인수검증표](../../testing/ACCEPTANCE.md)를 사용합니다. 본인의 기능 테스트는 이 문서 작성으로 실행된 것이 아닙니다. 실제 검증 시 아래 기록을 채웁니다.
