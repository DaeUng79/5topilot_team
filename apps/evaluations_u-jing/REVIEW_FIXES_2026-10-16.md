# 사용자 검토 4개 항목 반영

이번 사용자 요청을 기준으로 SA-03, SA-04, PM-07의 연결 코드만 조정했다. 기존 v2 원본 파일 및 오대웅 소스는 변경하지 않았다. 사용자 요청에 따라 PM-07 등록 창의 실행 시 배치와 SA-03 부서 입력 방식을 변경한 것이며, 다른 화면 디자인 변경을 허용하는 것으로 해석하지 않았다.

## 반영 내용

1. **SA-03 사업 등록의 부서**: 선택 상자를 직접 입력 칸으로 변경. 같은 소속·부서는 기존 ID를 재사용하고 새 이름은 총괄 권한으로 부서를 생성해 FK를 연결한다. 사업 검증 실패 시 부서 생성도 롤백한다. 부서관리자는 이 경로로 다른 부서를 생성할 수 없다. SA-02 계정의 부서 배정 및 검색 필터는 기존대로 유지한다.
2. **SA-04 위원 풀**: 화면 전체를 문서 기능으로 차단하던 분류를 수정. 기존 COM-01을 사용해 등록 부서별 실제 후보와 참여 횟수를 조회한다. 검색·부서 필터·탭 전환을 연결했다. 기존 탭에 없는 등록/수정 버튼은 추가하지 않았으며, 등록·수정은 PM-07에서 한다.
3. **결과 자료·보관·폐기**: ‘결과 자료 등록’은 외부 회의록·스캔본 등을 보관하는 기능이다. ‘결과 첨부자료 등록’으로 의미를 구분하고 기존 창에 설명과 파일 보관 연계 대기 상태를 표시했다. 실제 파일 업로드를 구현했다고 표시하지 않는다. 위원장이 최종 제출한 시스템 결과는 실제 DB에서 자동 조회·다운로드한다. 기존 가상 파일 14건을 실제 보관 자료처럼 표시하지 않는다. 보관 기간과 폐기 승인 절차는 기존 시안에도 미정이므로 임의로 활성화하지 않았고, 비활성 사유를 화면에 표시했다. 실제 폐기 또는 문서 원본 변경은 없다.
4. **PM-07 위원 등록·수정 창**: 등록 범위를 최상단에 배치하고 이름/휴대전화, 소속/부서, 직책/분야를 각각 같은 줄로 배치. 이메일은 마지막 줄에 둔다. 이 창에만 CSS를 적용해 입력 폭·간격을 조정했다. 좁은 휴대폰 화면에서는 1열로 돌아간다.
