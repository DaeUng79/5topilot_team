# 평가위원 관리 화면 시안

2026-10-13 작성. `index.html`을 브라우저에서 열거나 로컬 HTTP 서버로 확인한다.
외부 서비스·폰트·라이브러리 의존성이 없다. ES module 사용으로 HTTP 실행을 권장한다.

```powershell
python -m http.server 5186 --bind 127.0.0.1 --directory apps/committee_Lex6won/design
```

## 확정된 업무 요구사항

- 선택한 분야 전체를 한 모집단으로 합쳐 최종 정원 7·8·9명을 지정한다. 분야별 정원은 없다.
- 1차 예비명단은 정원의 3배수: 21·24·27명이다. 복수 분야 후보를 중복 집계·선정하지 않는다.
- 실제 추첨은 서버에서 비복원 무작위 추출하며 모집단과 결과를 보존한다.
- 담당자가 통화 결과를 기록하고 예비명단 안에서 최종 정원만큼 선택해 확정한다.
- 최종위원과 평가과제를 연결한다. 위원은 해당 과제 접근 시 인증과 배정 여부 확인을 거친다.

## 확인한 부서 서식

암호화된 XLSX 원본은 읽기 전용으로 열었으며 수정하거나 복호화 사본을 만들지 않았다.
Sheet1: 헤더 1행, 후보 129행, 14개 열. 성명·휴대전화는 129행 모두 공란, 전문분야 공란은 5행이다.

연번, 소속, 직위, 성명, 생년월일, 근무 지역, 구분, 부서, 전문분야, 휴대전화, 비고,
1차 선정 여부, 최종 선정 여부, 발주사업명.

- 연번은 원본 행 추적용이며 DB 후보 식별자는 별도로 발급한다.
- 복수 분야는 쉼표 기준으로 나눈다. AI와 인공지능 통합 표시는 시안 제안이며 원문을 유지한다.
- 후보 기본 정보와 사업별 선정 이력을 분리한다. 원본의 선정 표시로 평가 권한을 부여하지 않는다.
- 성명 누락 자료는 보완 대상으로 처리한다. 연락처 누락은 통화·인증 준비가 안 된 상태로 표시한다.
- 원본 개인별 행, 암호, 복호화 자료는 코드·문서·로그에 저장하지 않는다.

## 시안 범위

화면: 인력풀 등록·조회, 3배수 예비명단, 통화·최종 선정, 과제 배정·인증 연결.
129명의 합성 이름·소속·연락처와 원본에서 확인한 분야별 집계만 사용한다.
추첨 예시는 순서대로 표시한다. 실제 무작위 추첨·XLSX 업로드·DB·인증 기능이 아니다.
새로고침하면 모든 시안 상태가 초기화된다. 문자·초대·외부 API 호출이 없다.
