# 제안요청서 문서 챗봇

이 챗봇은 제안요청서(HWPX)에 있는 글과 표를 읽고 질문에 답합니다.
어려운 말로는 "문서를 읽고 답을 찾아 주는 도우미"입니다.

## 실행하기

프로젝트의 맨 위 폴더에서 아래 명령을 차례로 실행합니다.

```bash
python -m pip install -r apps/documents_daeung/requirements.txt
python -m streamlit run apps/documents_daeung/streamlit_parser_test_page.py
```

열린 페이지에서 HWPX 문서를 등록하고 선택한 다음 **문서 챗봇** 탭을 엽니다.
화면 코드는 [`../documents_daeung/streamlit_parser_test_page.py`](../documents_daeung/streamlit_parser_test_page.py),
챗봇 기능은 [`chatbot.py`](./chatbot.py), 챗봇 화면은 [`streamlit_chat.py`](./streamlit_chat.py)에 있습니다.

OpenAI AI 서비스를 사용하려면 `OPENAI_API_KEY`라는 비밀 키가 필요합니다.
프로그램은 키를 환경 변수, Streamlit secrets, 프로젝트 맨 위 폴더의 `.env` 순서로 찾습니다.
비밀 키를 README나 코드에 적거나 GitHub에 올리지 마세요.

## 화면에서 질문하기

- **사이드바**: 질문 범위 선택, AI에게 보낼 자료 확인·다운로드, 대화 초기화
- **중앙 화면**: 질문과 답변이 나타나는 곳
- **화면 맨 아래**: 질문 입력창. 이 입력창은 **문서 챗봇** 탭을 열었을 때 나타납니다.

질문 범위는 세 가지입니다.

1. **현재 문서**: 사이드바에서 고른 문서 한 개를 읽습니다.
2. **문서 직접 선택**: 여러 문서를 골라 함께 질문할 수 있습니다.
3. **등록된 사업**: 같은 사업에 연결된 문서를 함께 읽습니다. 연결된 문서가 없다면 직접 골라 주세요.

화면에서 특정 쪽을 보고 있어도, 챗봇은 고른 문서의 **전체 페이지**를 읽습니다.

## 어떤 자료를 AI에게 보내나요?

질문을 보낼 때마다 선택한 문서의 글과 표, 대화 내용이 OpenAI로 전송됩니다.
AI가 문서를 자동으로 기억하는 것은 아니므로 질문할 때마다 문서 자료를 다시 보냅니다.
따라서 회사나 개인의 중요한 정보를 보내도 괜찮은지 먼저 확인하세요. 질문할 때마다 사용량과 요금이 생길 수 있습니다.

AI에게 보내지 않는 자료도 있습니다.

- 문서에 들어 있는 그림은 보내지 않습니다.
- 그림 속 글자도 읽지 않습니다. 그림에서 글자를 찾아내는 기능(OCR)은 사용하지 않습니다.
- 문서의 내용을 짧게 요약하거나 길다고 임의로 잘라 보내지 않습니다.

사이드바의 **챗봇에 전달하는 추출 자료 확인**을 열거나 JSON 파일을 내려받으면
AI에게 실제로 보낼 자료를 볼 수 있습니다. 이 자료는 `compact-v2`라는 간단한 형식으로 정리됩니다.
반복되는 꾸밈 정보와 불필요한 공백은 줄이지만, 글의 내용·페이지·표의 칸과 병합 정보는 보존합니다.
원본 HWPX와 데이터베이스는 바뀌지 않습니다.

## 답변을 확인할 때

AI는 근거가 있는 페이지를 `[페이지번호 N쪽]`처럼 표시하도록 안내받습니다.
문서에서 찾을 수 없는 내용은 확인할 수 없다고 답해야 합니다. 그래도 답이 항상 맞는 것은 아니므로
중요한 내용은 표시된 쪽과 원본 문서를 직접 비교하세요.

표를 보여 달라고 하면 AI가 표를 새로 만들어 내는 대신, 데이터베이스에 저장된 원래 표를 화면에 표시합니다.
문서에서 표를 찾지 못하면 원래 표를 보여줄 수 없습니다.

## 문서가 너무 클 때

AI가 한 번에 읽을 수 있는 양에는 한도가 있습니다. 이 프로그램은 문서·질문·대화의 크기를 미리 확인합니다.

- 문서와 질문만으로 한도를 넘으면 질문을 보낼 수 없습니다. 문서 수를 줄이거나 질문을 짧게 해 주세요.
- 대화가 너무 길면 오래된 질문과 답변부터 이번 전송에서 제외하고 화면에 알려 줍니다.
- 문서의 내용을 자동으로 잘라 보내지는 않습니다.

대화는 현재 Streamlit 세션에서만 보관하며 데이터베이스에는 저장하지 않습니다.
선택한 문서나 문서의 파싱 버전이 바뀌면 이전 대화를 지웁니다.

## 자료를 줄인 예시

2026-10-13에 등록된 문서 5개를 하나씩 선택해 비교한 결과입니다.
토큰은 AI가 읽는 글의 양을 세는 단위입니다. 실제 결과는 문서와 질문에 따라 달라집니다.

| 문서 | 이전 형식 | 현재 형식 | 줄어든 양 |
| ---- | --------: | --------: | --------: |
| 1    |    54,768 |    51,154 |      6.6% |
| 2    |    46,249 |    40,423 |     12.6% |
| 3    |    75,209 |    70,164 |      6.7% |
| 4    |   108,919 |    98,686 |      9.4% |
| 5    |    47,630 |    43,886 |      7.9% |

이 비교는 문서 자료만 센 결과입니다. 여러 문서를 함께 고르거나 긴 질문·대화를 더하면 한도를 넘을 수 있습니다.

## 자동 테스트

아래 명령으로 테스트를 실행합니다.

```bash
python -m unittest discover -s apps/ai_chatbot_daeung/tests -v
```

테스트는 임시 문서로 문서 선택, 표 표시, 자료 크기 제한, 대화 흐름 등을 확인합니다.
실제 OpenAI 유료 호출은 하지 않습니다.
