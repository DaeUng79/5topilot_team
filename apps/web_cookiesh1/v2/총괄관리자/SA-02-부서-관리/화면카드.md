# 화면 카드: SA-02 부서·계정
상태: 🟨 시안 · 2026-10-16 · 담당: A · 총괄관리자

| 항목 | 내용 |
|---|---|
| 이 화면의 일 | 시스템을 쓸 부서(소속)와, 그 부서가 로그인할 관리자 계정·권한을 관리한다 (탭 2개) |
| 탭 [부서] (**기능명세 v2에 없음 · 팀 확인 필요** 문구를 칸에 표시) | 부서 코드 · 소속 · 명칭 · 계정 수 · 사업 수 · 상태 |
| 부서 탭 주 버튼 | [부서 등록] (등록 칸: 부서 코드 · 소속 · 명칭) |
| 부서 수정·삭제 | 행을 눌러 수정 · 코드는 못 바꿈 · 사업 수>0이면 삭제 대신 [비활성으로 바꾸기], 0이면 [삭제](확인 창) |
| 탭 [관리자 계정] (ADM-01) | 아이디 · 이름 · 부서 · 권한 · 마지막 로그인 · 상태 · **검색어·부서·상태 + [초기화] + 쪽 이동(5개씩)** |
| 계정 탭 주 버튼 | [계정 등록](ADM-02) 칸: 아이디 · 이름 · 부서 · 초기 비밀번호 [생성] · 아이디 중복이면 "이미 있는 아이디예요" · 부서마다 계정 1개(이전 결정 유지) |
| 계정 수정 | 행을 눌러 표시명·부서 [수정 저장](ADM-03) · **권한 코드 체크 목록 + [권한 저장]**(ADM-05, "저장하면 그 계정은 다시 확인돼요") · 비밀번호 초기화 · [삭제 / 비활성](ADM-04, 기록은 남기고 세션 끊김 안내) · 마지막 활성 총괄은 "잃을 수 없어요"(비활성·계정 관리 권한 해제 불가) |
| 동시 수정 충돌 | "다른 곳에서 먼저 바뀌었어요" 차분한 창 · [새로 불러오기] (시안 보기 줄의 [저장할 때 충돌 나게]로 확인) |
| 상태 | 아이디·부서 코드 중복 · 비활성 · 마지막 총괄 보호 · 계정 있는 부서는 등록 목록에서 선택 불가 |
| 테이블 | 쓰기 department, account, audit_log (version 컬럼으로 충돌 확인) |
