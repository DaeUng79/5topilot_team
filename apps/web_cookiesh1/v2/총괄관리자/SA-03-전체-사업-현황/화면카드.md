# 화면 카드: SA-03 전체 사업 현황
상태: 🟨 시안 · 2026-10-16 · 담당: A · 총괄관리자

| 항목 | 내용 |
|---|---|
| 이 화면의 일 | 모든 부서의 사업을 한눈에 보고, 필요하면 고치거나 지운다 |
| 보여 줄 것 | 사업 목록: 사업명 · 부서 · 담당자 · 평가일 · 상태(준비/평가 중/완료) · 제출 n/N |
| 찾기 (PRJ-01) | 검색어·부서·상태 거르기 + [초기화] + 쪽 이동(6개씩) |
| 등록 (PRJ-02) | [사업 등록] 칸: 사업명 · 소속 · 부서 · 직책/직급 · 성명 · 전화 · 이메일(선택) |
| 수정·삭제 | 평가 시작 뒤엔 **사업 식별(사업명·소속·부서)·평가조건(평가일) 잠금**(🔒 "평가가 시작돼 바꿀 수 없어요"), 담당 정보는 수정 가능(PRJ-03) · 삭제는 **사유 필수**, 목록에서만 제외, "서명 자료는 보존돼요"(PRJ-04) · 평가 시작 뒤 삭제 버튼은 막음(진행 평가 취소는 별도 정책) |
| 상세·자료 (PRJ-05) | 행을 누르면 오른쪽 칸에 **구분된 구역** 사업 정보 · 자료 · 진행 단계 · 변경 이력. 자료 = 파일별 [내려받기] + [전체 내려받기 (ZIP)], 경로·ZIP 이름은 사업명 기준(`사업명/제안요청서·제안서·결과/파일`, `사업명_자료.zip`), 잠긴 사업도 내려받기 가능(문서 DB / 평가 DB 준비 배지 따로). 목록에도 준비 상태 배지 |
| 테이블 | 읽기 project, department, project_member, score(제출 수) / 쓰기 project, audit_log |
