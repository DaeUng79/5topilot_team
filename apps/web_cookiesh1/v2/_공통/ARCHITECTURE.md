# 전체 구조
상태: 초안 · 2026-10-16

```
[웹 하나 · React]
 ├─ /admin   총괄관리자 · /manage 사업담당자 (입장로 분리)  A 담당
 └─ /eval    평가위원 (위원장만 '평가결과 확인' 메뉴 추가)       B 담당
        │ HTTP API
[API 서버 하나 · Python]
 ├─ 계정·권한   ├─ 사업·문서 등록   ├─ 위원 풀·추첨·명단
 ├─ 문서 변환(HWPX/PDF → 쪽 이미지 + 목차)
 ├─ 평가·집계(최고·최저 제외 평균)   └─ 챗봇(팀원 코드 연결)
        │
[DB 3개 · SQLite: admin · documents · evaluation (팀 기획서)]  +  [파일 저장소]
```

| 부분 | 정한 것 | 정할 것 |
|---|---|---|
| 웹 | 지금 React 앱 재사용, `/admin` · `/eval` 두 갈래 | — |
| API | Python (팀 파서·챗봇이 Python) | 프레임워크 (FastAPI 권장) |
| DB | 테이블 정의를 코드로 관리 → SQLite로 시작해 PostgreSQL로 옮길 수 있게 | 최종 DB · 공유 방식 |
| 파일 형식 | 제안요청서 **HWPX**, 제안서 PDF (PPT는 PDF로 받기 권장) | 스캔본 안내 문구 |
| 목차 | 자동 추출 → **부서관리자가 확인·수정** (제안요청서·제안서 둘 다) | 추출 성공률: 샘플로 검증 |
| 로그인 | 관리자: 아이디·비밀번호 / 위원: **이름 + 전화번호** | 틀린 횟수 잠금 |

## 재사용 (exp/desk-metaphor에서)
- 쓰는 것: 읽기 화면(목차 → 쪽 이동, 두 쪽/한 쪽), 평가기준 목차 묶음, 평가·제출, 디자인 토큰(`styles.css :root`)
- 버리는 것: 5단계 홈, 사업 설명, 업체 발표, 메모·형광펜·책갈피·메모 폐기
