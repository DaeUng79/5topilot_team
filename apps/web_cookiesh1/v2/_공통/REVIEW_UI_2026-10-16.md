# UI 점검 (Refactoring UI) 2026-10-16

요청: "ui 좀 지저분한거 같아서 한번 리팩토링으로 점검해줘(기능은 크게 안건드리는 선에서)"
범위: v2 시안 전체(입장 · SA-00~04 · PM-00~08 · EV-00~07) + 공유 파일 5개(`_shell.css` `_steps.css` `_ui.js` `_eval.css` `_eval.js`). 흐름·버튼·ID·데이터는 그대로.

## 요약
1. 가장 어지러운 곳은 **위원 쪽 공유 CSS**(글자 11종·둥글기 17종·굵기 800)와 **화면 아래 "시안 보기" 줄**(큰 회색 띠, 두 줄로 넘치기도 함). 둘 다 공통 값으로 맞췄다.
2. 테두리·상자·색 칩을 줄이고(단계 막대, 알림 상자, 표 머리, 목록 칸, 준비 상태 칩), 상태 칩은 **중립 / 강조(파랑) / 주의(노랑·빨강)** 로 정리, 완료는 초록 글자+✓.
3. 총괄·사업담당자·위원 세 영역이 같은 토큰(색·글자·둥글기·그림자)을 쓰게 했다. 1366×768에서 모든 화면 쪽 스크롤 없음, 콘솔 오류 0.

## 남긴 것 (기능·결정 때문에 못 고친 것)
- **워터마크 글자 96·120px**(PM-06, EV-07 「미확정」)과 입장 화면 타일 둥글기 24·28·36px: 그림 요소라 유지.
- **단계 표시 3종**(PM-03 흐름 칩, PM-04 위 탭, PM-05 왼쪽 목록)이 각자 모양: 화면마다 정보량이 달라 통합하려면 구조를 바꿔야 함.
- **SA-01 오른쪽 목록 색 띠 3색**: "목록을 시각적으로 구분" 결정(DECISIONS) 때문에 유지.
- **조절 가능한 인라인 스타일**: 일부 화면 `<style>` 안에 한 곳에서만 쓰는 규칙이 남아 있음(예: PM-04 표 높이). 공유 CSS로 올리려면 화면 카드 재검토 필요.
- 위원 쪽 시안 상태(펼침 줄)는 기본이 접힌 상태라, 상태 그림(`*-xxx.png`)을 다시 뽑는 스크립트는 먼저 「시안 상태」를 눌러야 한다.
- 상태별 부가 그림(`login-error.png` 등)은 다시 찍지 않음. 화면마다 대표 그림 1장만 새로 덮어씀(`rui-before/after-*.png`는 임시 폴더).
