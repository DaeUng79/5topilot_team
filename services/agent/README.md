# 핵심 Python 담당자 작업 공간

기존 `computer_agent.py`의 동작/실행법은 루트 README.MD를 참고한다. 이 기반 작업은
기존 코드를 수정하거나 자동 실행하지 않았다. Python 담당자는 계속 그 파일에서 개발할 수 있다.

새 문서 처리 기능은 독립 테스트 가능한 라이브러리/서비스로 추출하고
`apps/api/app/modules/ai/`의 어댑터를 통해 연결한다. 웹 앱의 import 경로에
PyAutoGUI나 PC 제어 초기화가 들어가지 않아야 나머지 3명이 Gemma 없이 개발할 수 있다.

첫 계약은 document_id, job_id, status, page, quote, 오류 코드로 시작한다.
시간이 긴 문서 처리는 요청 시 job_id 반환 → 상태 조회 → 결과 조회로 확장한다.
제안서 안의 텍스트를 도구 실행 지시로 취급하지 않는다. AI가 DB의 평가점수를 직접 갱신하지 않는다.

실제 PC 제어가 필요한 경우에는 신뢰된 운영자의 로컬 도구로 별도 실행하고,
웹의 임의 문자열을 기존 `/run`으로 전달하는 연결은 만들지 않는다.
