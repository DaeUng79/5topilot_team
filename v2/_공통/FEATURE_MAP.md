# 기능 → 화면 연결표
기준: 팀 기획서 `AUTOPILOT_DB_MODULE_SPEC.html` 12장 (기능 38개) · 2026-10-16 · DB 작업 중이라 바뀔 수 있음
원칙: 화면은 DB 칸이 아니라 **기능의 출력 모양**(예: `ProjectRead`)에 맞춰 만든다. DB가 바뀌어도 출력 모양이 같으면 화면은 그대로다.

## 화면이 필요한 기능
| 기능 ID | 기능 | 화면 | 화면이 꼭 보여 줄 상태 (기획서 규칙에서) |
|---|---|---|---|
| ADM-03 | 관리자 아이디·비밀번호 로그인 | ENTRY, SA-00, PM-00 | 오류 문구는 하나로 통일 · 시도 제한 잠금 |
| ADM-01 | 부서관리자 계정·권한 | SA-02 | 총괄만 · 마지막 총괄 삭제 차단 · 권한 바뀌면 그 계정 로그아웃 |
| ADM-02 | 소속·부서 | SA-02 | 사업이 있는 부서는 삭제 대신 비활성 |
| ADM-04 | 총괄 대시보드 | SA-01 | 기간·부서·상태 거르기 · "기준 시각" 표시 |
| PRJ-01 | 사업 검색·등록·수정·보관 | SA-03, PM-01 | 내 부서 범위만(사업담당자) · 동시 수정 충돌 |
| PRJ-02 | 제안 업체 | PM-02 | 평가 시작 뒤 표시 코드(A사…) 변경 불가 |
| PRJ-03 | 사업별 자료·결과 한눈에 | PM-01 상세, SA-03 상세 | **아직 반영 안 됨(미동기화)** 표시 |
| DOC-01 | 문서 검색·등록·교체·보관 | PM-02, SA-04 | RFP는 HWPX, 제안서는 HWPX·PDF · 교체하면 새 버전 |
| DOC-02 | 파일 검증·저장·내려받기 | PM-02, EV-03, EV-04 | 형식·크기 거절 문구 · 내려받기도 권한 확인 |
| DOC-05 | 파싱 작업·재시도 | PM-02 | 대기 · 처리 중 · 완료 · 실패 → [다시 시도] |

| DOC-06 | 목차·원문 보기, 수동 연결 | PM-02(확인·연결), EV-03, EV-04 | 쪽 미확인 표시 · 평가 시작 때 고정된 버전만 보임 |
| CRI-01 | 평가표 추출·확인·확정 | PM-03 | 원문 근거 없는 항목은 자동 확정 금지 |
| DOC-07 | 항목별 제안서 비교 | EV-05 | 출처 없는 내용은 만들지 않음 |

| COM-01 | 부서 풀·사업 후보 | PM-07, PM-04 | 사업에 직접 넣은 후보는 풀에 자동으로 안 들어감 |
| COM-02 | 엑셀 미리보기·확정 | PM-04, PM-07 | 미리보기에서 오류·중복 표시 후 확정 |

| COM-06 | 본위원·예비 명단 확정 | PM-04 | 인원·분야·연락 가능 검증 · 평가 시작 전만 |

| EVA-01 | 평가 시작(참여자·업체·기준 잠금) | PM-05 | 최소 인원·기준 미확정이면 막힘 |
| EVA-02 | 위원장 지정 (참석자 중) | PM-05 | 평가 시작 뒤 참석 확정자 중에서만 |
| EVA-03 | 점수·의견 입력·저장 | EV-06 | 범위·간격 검증 · 제출 뒤 수정 불가 |
| EVA-04 | 개인·위원장 서명 | EV-06, EV-07 | 서명 뒤 점수를 바꾸면 제출 막힘 |
| EVA-05 | 개인 평가 제출·잠금 | EV-06 | 모든 업체·항목을 한 번에 잠금 |
| RES-01 | 최고·최저 제외 평균·순위 | EV-07 | 전원 제출 전엔 계산 안 함 |
| RES-02 | 위원장 최종 확인·제출 | EV-07 | 현재 위원장만 |
| RES-03 | 확정 결과 조회·내보내기 | PM-06, SA-03 | 위원장 제출 뒤에만 |
| AUD-01 | 변경 기록 (화면은 보기만) | SA-01 [확인할 일] | 인증값·원문·서명 이미지는 안 보임 |
