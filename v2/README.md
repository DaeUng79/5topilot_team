## 흐름
```
부서: 사업 등록 → 문서·목차 확인 → 평가항목 확인 → 위원 3배수 → 랜덤 선정
                                                        ↓ project_member
위원: 로그인 → 참석 확인 → 제안요청서 / 제안서 / 평가하기 → 제출
                                                        ↓ score
위원장: 평가결과 확인 → 서명 → 부서: 결과 보기
```
