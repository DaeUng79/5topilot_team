## 흐름
```
사업담당자: 사업 등록 → 문서·목차 확인 → 평가항목 확인 → 정원·분야 → 분야별 3배수 추첨 → 전화 확인 → 명단 확정 → [평가 시작]
                                                        ↓ project_member
위원: 로그인 → 참석 확인 → 제안요청서 / 제안서 / 평가하기 → 제출
                                                        ↓ score
위원장: 평가결과 확인 → 서명 → 사업담당자: 결과 보기
```
