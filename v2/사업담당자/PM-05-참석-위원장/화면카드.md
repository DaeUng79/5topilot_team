| 앞 화면 → 이 화면 → 다음 화면 | PM-04 ④ → PM-05 ⑤ 참석·위원장 → PM-06 ⑥ 결과 (위원장 확인 뒤 열림) |

| 사용자가 답할 질문 | "평가를 시작해도 되나요?" → [평가 시작] · "누가 위원장인가요?" → [지정] |
| 보여 줄 것 (최대 4개) | 시작 전 점검 3개(최소 인원·평가표 확정·업체 문서 준비) · 위원별 참석 상태 · 동의 여부 · 구분(본위원/예비) |
| 숨길 것 (눌렀을 때) | 점검 기준 숫자는 모자랄 때만 이유로 · 위원장 고르는 칸은 평가 시작 뒤에만 |
| 주 버튼 1개 / 보조 버튼 | 시작 전 [평가 시작] / 시작 후 [지정] / 지정 뒤 [결과 화면 보기] |
| 막는 조건 · 경고 | 참석 확정(참석+동의) 최소 5명 미만 · 평가표 미확정 · 업체 문서 미준비 → [평가 시작] 꺼짐 · 위원장은 참석 확정자만 선택 |
| 상태 | 응답 전 · 참석 · 불참 · 동의 안 함 · 인원 모자람(막힘) · 평가 중(잠금) · 위원장 지정됨 |
| 읽는 테이블 / 쓰는 테이블 | 읽기 project_member, criterion, vendor, document / 쓰기 project(상태·잠금), project_member(위원장), audit_log. 참석·동의는 위원이 입력(읽기 전용) |
