# 화면 카드: PM-01 사업 목록·등록
상태: 🟨 시안 · 2026-10-16 · 담당: A · 사업담당자

| 항목 | 내용 (항목당 한 줄) |
|---|---|
| 누가 · 언제 | 사업담당자 · 로그인 직후, 사업을 새로 만들거나 이어서 할 때 |
| 앞 화면 → 이 화면 → 다음 화면 | PM-00 → PM-01 목록 → 사업 상세(① 사업 정보) → PM-02 |
| 이 화면의 일 (한 문장) | 우리 과 사업을 찾아 열고, 새 사업을 등록한다 |
| 사용자가 답할 질문 | "어느 사업을 이어서 할까요?" → [사업 등록] 또는 행 누르기 |
| 보여 줄 것 (최대 4개) | 사업명 · 담당자 · 평가일 · 진행 단계(번호+이름+점) · 상태 — 내 부서 사업만 |
| 숨길 것 (눌렀을 때) | 등록 항목은 오른쪽 칸 · 상세는 overview.html(사업 정보 + 한눈에 보기) |
| 주 버튼 1개 / 보조 버튼 | [사업 등록] / 사업명 검색 |
| 상태 | 빈 목록 · 검색 결과 없음 · 입력 오류(사업명·담당자·직급·전화) · 평가 중·완료는 단계 막대 표시 · 동시 수정 충돌 |
| 등록 항목 | 사업명 · 담당자 이름 · 소속(기본 부서) · 직급 · 전화 · 이메일(선택) · 평가일(선택, 시안에서 추가) |
| 상세 한눈에 보기 | 문서 준비 n/m · 평가위원 확정 여부 · 결과 여부 · “아직 반영 안 됨” 배지(PRJ-03) · [새로 고침] |
| 단계 막대 | ① 사업 정보 ~ ⑥ 결과, 순서대로 열림 · 잠긴 단계는 🔒 + “앞 단계를 먼저 끝내 주세요” (`사업담당자/_steps.css`) |
| 읽는 테이블 / 쓰는 테이블 | 읽기 project, department, document, vendor, result_confirm / 쓰기 project, audit_log |
| 기능 카드 | `PM-01-01` 목록·검색 · `PM-01-02` 등록 · `PM-01-03` 사업 정보 수정 · `PM-01-04` 한눈에 보기 |
