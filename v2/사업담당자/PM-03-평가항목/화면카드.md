# 화면 카드: PM-03 평가항목
상태: 🟨 시안 · 2026-10-16 · 담당: A · 사업담당자

| 항목 | 내용 (항목당 한 줄) |
|---|---|
| 누가 · 언제 | 사업담당자 · 문서 단계를 끝낸 뒤(③ 단계) |
| 앞 화면 → 이 화면 → 다음 화면 | PM-02 ② → PM-03 ③ → PM-04 ④ 평가위원 |
| 이 화면의 일 (한 문장) | 제안요청서에서 읽어 온 평가표(항목·배점·근거 쪽)를 확인하고 확정한다 |
| 사용자가 답할 질문 | "평가표가 원문과 맞나요?" → [확정] |
| 보여 줄 것 (최대 4개) | 평가 항목 · 배점 · 근거 쪽 · 합계와 기술 배점(80점) 비교 |
| 숨길 것 (눌렀을 때) | 원문 보기는 근거 쪽 번호로 (시안은 쪽 번호만) |
| 주 버튼 1개 / 보조 버튼 | [확정](문제가 있으면 꺼짐 + 이유 문구) / 확정 뒤 [다음: 평가위원] |
| 확정 막는 조건 | 합계 ≠ 기술 배점 · “원문 확인 필요”(근거 쪽 없는 항목) 1개라도 있음 — 자동 확정 금지(CRI-01) |
| 상태 | 합계 불일치 오류 · 원문 확인 필요 · 문제 없음 · 확정됨(잠금 표시, 입력칸이 글자로 바뀜) · 빈 목록(제안요청서 없음)은 PM-02로 안내 |
| 읽는 테이블 / 쓰는 테이블 | 읽기 document, criterion / 쓰기 criterion(확정 여부), audit_log |
| 기능 카드 | `PM-03-01` 평가표 보기·고치기 · `PM-03-02` 근거 쪽 입력 · `PM-03-03` 확정 |
