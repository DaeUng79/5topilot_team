| 항목 | 내용 (항목당 한 줄) |
|---|---|
| 누가 · 언제 | 모든 사용자 · 첫 접속 |
| 앞 화면 → 이 화면 → 다음 화면 | |
| 이 화면의 일 (한 문장) | 내 입장 고르기 |
| 사용자가 답할 질문 | "어떤 일로 오셨나요?" → 아이콘 하나 |
| 보여 줄 것 (최대 4개) | 아이콘 3개 + 이름 (평가위원 · 사업담당자 · 총괄관리자 순, 총괄은 회색 톤) |
| 숨길 것 (눌렀을 때) | 설명 한 줄(올렸을 때), 로그인 칸(누른 뒤) |
| 주 버튼 1개 / 보조 버튼 | 아이콘 / ‹ 다른 입장 선택 |
| 상태 | 로그인 실패 · 잠금 |
| 읽는 테이블 / 쓰는 테이블 | DB_CONTRACT 기준 |
| 기능 카드 | `ENTRY-01`, `ENTRY-02` … |
